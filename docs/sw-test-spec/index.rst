SW Test Specification
=====================

This document lists the software test cases and what each one verifies.

.. note::

   This is a skeleton. The content comes in Phase 5.

What will go here
-----------------

* the SW test cases, read from the ztest suites in ``tests/``. Each test case has an ID from the
  ledger, written into the comment above the test, and names the SW requirements it verifies;
* how the tests run: on ``native_sim`` in CI and locally, and on the NUCLEO-G474RE board.
