SW Architecture and Design
==========================

This document describes how the robot arm firmware is built: its architecture and its detailed
design.

.. note::

   This is a skeleton. The content comes in Phase 6.

What will go here
-----------------

* the SW architecture elements (modules, threads, interfaces) and the SW requirements and
  system model elements they meet;
* the detailed design of each module;
* the devicetree of the firmware and the result of the check that compares it with the system
  model (pins, buses, channels, trace IDs).

In iteration 1 the architecture is written in reStructuredText. A SysML sub-model of the software
may follow in iteration 2.
